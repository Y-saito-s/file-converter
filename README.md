# File Converter

画像とPDFをブラウザ内で処理する静的Webアプリです。GitHub Pagesで公開できます。

## できること

- 画像を1つのPDFにまとめる
- 画像を1枚ずつPDFに変換（複数件はZIP）
- 複数PDFを結合
- PDFを1ページずつに分割（ZIP）
- PDFをJPGに変換（ZIP）
- ファイルのドラッグ＆ドロップ、並び替え、削除

対応画像形式：JPG/JPEG、PNG、WebP、GIF、BMP、HEIC/HEIF、AVIF（ブラウザと画像デコーダーの対応状況によります）。

## ローカルで使う

`index.html` をモダンなブラウザで開いてください。ライブラリはCDNから読み込むため、初回利用時はインターネット接続が必要です。ブラウザの制限により、ローカルファイルからの実行でPDF.jsが正常に動かない場合は、VS CodeのLive Serverなどでローカルサーバーを起動してください。

## GitHub Pagesで公開

1. GitHubで新しいリポジトリを作成します。
2. `index.html`、`style.css`、`script.js`、`README.md` をリポジトリ直下にアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Deploy from a branch** を選び、`main` ブランチの `/ (root)` を指定して保存します。
5. 公開されたURLを開き、画像とPDFの両方でテストします。

## プライバシー

ファイルの読み込みと変換はブラウザ内で行い、ファイル内容を独自サーバーへ送信するコードはありません。ただし、変換ライブラリの読み込みに外部CDNを使用します。完全オフライン運用にはライブラリをローカル配置する必要があります。

## 注意事項

- HEIC/HEIFは `heic2any` による変換を試みます。ファイルやブラウザによっては変換できない場合があります。
- 大きなファイルやページ数の多いPDFは、メモリ不足やブラウザの制限で失敗する場合があります。
- PDFをJPGへ変換するときは、ページを倍率1.7でレンダリングします。
- PDF内のフォーム、しおり、特殊な構造などは、結合時に完全には保持されない場合があります。

## 音声・動画変換

MP3/M4A から WAV、動画から MP3 への変換には FFmpeg.wasm を使用します。初回は変換エンジンの読み込みが必要で、インターネット接続が必要です。大きなファイルはブラウザのメモリを多く使用します。
